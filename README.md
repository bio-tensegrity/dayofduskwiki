# Day of Dusk Wiki

The [**Day of Dusk Wiki**](https://dayofdusk.wiki) documents [*Day of Dusk: The Border*](https://www.roblox.com/games/1927139201/Day-of-Dusk-The-Border-Beta), a post-apocalyptic roleplay game on Roblox by [dylanjkl](https://www.roblox.com/users/17319802/profile/). Hosted on GitHub Pages, it’s a fast, ad-free alternative to Fandom, covering lore, mechanics, locations, and guides.

## About

This wiki is a resource for *Day of Dusk* players, offering clear, organized information without Fandom’s ads or trackers. It’s community-driven and hosted on GitHub Pages for accessibility.
